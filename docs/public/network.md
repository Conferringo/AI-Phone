# Workbench proxy

AImanity connects directly by default. Open **Proxy** next to the knowledge base, import a Clash-compatible YAML subscription URL, select a node and enable it. The selected rules apply to Android apps that use the system HTTP proxy, the Linux Chromium browser, workbench downloads and model connections. A proxy configured directly on a model takes priority.

Refresh the subscription from the same panel. The URL is stored locally. AImanity leaves the host system proxy unchanged.

## 中文

AImanity 默认直连。在知识库旁打开「工作台代理」，导入 Clash 兼容的 YAML 订阅地址，选择节点后启用。所选规则适用于遵循系统 HTTP 代理的 Android 应用、Linux Chromium、工作台下载和模型连接。单独为模型填写的代理优先。

订阅可在同一窗口更新，地址只保存在本机。宿主机系统代理保持原设置。
