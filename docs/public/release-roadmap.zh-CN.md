原生CI已构建过macOS ARM64、Windows x64、Linux x64/ARM64和Android ARM64目标；各修订结果分别记录，不代表全部可作独立宿主。Android独立宿主面向root/KVM设备。维护者豁免非macOS实机安装，未测仍记未验证；完整组件、编译、审计和分发依据继续必需。

默认 Android 手机目前仍由部署程序准备，网页内的 Android 安装器是额外实例路径；不能包装成已经完整的初次系统安装向导。本轮新增的是工作台内的配置引导与实际就绪检查。

## 最短交付顺序

1. **先完成一个可靠宿主**：macOS ARM64 干净主机，从下载、依赖检查、资源配置、设备创建到首次模型调用和文件交换。对失败、恢复、重新打开客户端建立验收记录。
2. **可审查的源码预览**：去掉用户状态的源码树、中英 README、架构/目录/部署/升级/隐私/免责/贡献文档、锁定依赖、许可声明、SHA256 清单。经审阅的无状态源码已公开到master，用户状态和私有研发历史不上传。
3. **客户端候选版**：签名/公证与平台原生测试；Android 独立宿主按root/KVM范围推进；服务器配置、用户文件、数据库、设备盘从更新目录分离。
4. **Windows/Linux 宿主扩展**：以 RuntimeProvider 接口封装虚拟化、驱动、镜像与网络差异，完成各平台干净安装后再增加支持标记。默认一手机一电脑，扩展口不等于已支持更多设备。
5. **升级闭环**：下载版本化制品 → 校验签名/哈希 → 备份状态 → 暂停接收新动作 → 迁移 → 健康检查 → 激活或回滚。不得用对工作目录直接 git pull 替代用户数据兼容方案。

## 模型与配置方向

- 引导继续使用唯一配置中心。设备绑定 Agent；Agent 拥有模型、连接应用、记忆；Skill、知识库、工作文件共享。
- 当前真实验证的是已有 DeepSeek；Responses 与 Chat Completions 是协议能力，不代表该协议下每个模型都支持视觉、工具和流式输出。
- 下一步增加模型发现，失败时保留手工模型 ID，并分别检测文本、视觉、工具、上下文容量。能力结果与 provider/model/config revision 关联，不能跨配置复用旧检测结果。
- Anthropic原生Messages已与Responses、Chat Completions共用执行框架，提供13项预设和隔离协议回归。新服务商实号API、OAuth及其他本地视觉模型仍需各自验收，不能以预设代替通过。

## 语音与电话方向（规划，尚未实现）

| 阶段 | 设计 | 验收条件 |
|---|---|---|
| V1 语音输入/播报 | Agent 下配置 STT/TTS；麦克风音频、设备音频、模型播报分轨；本地或云端适配器独立 | 中英噪声场景、断网回退、设备静音不影响麦克风权限、取消不丢已确认转写 |
| V2 实时语音 | VAD/端点检测、回声抑制、可打断 TTS、输入序号和播放 generation；复用持久消息队列与 steering | 连续打断、用户同时打字、重连去重；已执行设备动作不因打断重放 |
| V3 通话沙盒 | 独立 CallSession/TelephonyProvider，先 mock/SIP 测试；拨号/接听/挂断/DTMF/状态查询各有 action_id | 先落账本再发起通话；回调去重，未知结果先查询；重启不重复拨号；挂断后无晚到音频 |
| V4 真实通信 | 接入用户自行配置的合法电话服务或物理设备；号码、接收人、费用上限、录音选项明确 | 用户授权真实呼叫目标/范围，通话状态有服务商或设备证据；逐地区核查通信和录音要求 |

Android 模拟器的拨号界面不产生运营商线路；root、型号名称和 eSIM 界面都不能替代真实号码、服务商或蜂窝硬件。公网电话网关通常需要回调入口，和当前“仅局域网、无隧道”的部署约定不同，不能悄悄开放端口。优先支持用户已有的内网 SIP 或明确配置的通信适配器。

技术边界建议：DeviceRuntime 管设备，AgentRuntime 管执行和连续输入，MediaSession 管音频，TelephonyProvider 管线路。持久业务状态与动作账本落 PostgreSQL，Redis预留为可选缓存，当前不是任务队列；新业务协议先写 protobuf，媒体通道单独协商。语音不得绕过现有 run/device/epoch/action_id 的控制边界。

Apache-2.0 继续用于原创源码；第三方素材/依赖保留各自许可。免责声明描述能力、数据去向和限制，不能把免责文字当成滥用防护或第三方授权。语音与电话功能尚未实现，发行说明不得写成现有能力。
