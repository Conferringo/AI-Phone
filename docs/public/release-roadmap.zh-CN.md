# 开发路线

AI Phone 正在开发适用于 macOS Apple Silicon、Windows x64、Linux 和 root/KVM Android 的完整本地发行包。下载供应与平台限制统一见[发行状态](release-status.md)。以下规划能力需在实现与对应验收完成后才纳入发行。

## 完整本地安装

- 随包提供干净的 Android/Linux 系统基础、匹配模拟器、预构建服务与运行环境。
- 在一个客户端中完成手机、电脑与模型配置，支持资源准备续跑及真实设备就绪检查。
- 允许调整设备资源预设，保留已有设备盘、账号与聊天。默认工作区包含一台手机和一台电脑。
- 完成安装中断、宿主重启及更新恢复。四平台预览客户端的实机安装按维护者要求豁免并标记未测；编译、完整包内容与再分发审查仍是交付要求。

安装约定见[发行标准](preview-release.md)、[运行组件](runtime-bundles.md)及[一体化宿主](integrated-hosts.md)。

## 响应速度与持续工作

降低冷启动、设备控制及输入到响应的延迟，分别计量冷/热状态下的画面采集、传输、模型调度与播放。用户补充应及时调整当前任务，不必等待长时间的前台操作或重新建立对话。

设备动作在取消与恢复后保留原有身份，未知结果先观察再决定后续操作。长时后台任务保留检查点，通知与用户指令共用同一持久会话路径。

## 模型与连接应用

模型/API、连接应用与记忆归入各自 Agent，设备绑定保持明确；Skill、知识库和工作文件共享。

继续扩展模型发现与手动 ID 回退、绑定配置版本的能力检测、服务商协议回归、OAuth 和本地模型。协议兼容不等于每个模型均具备视觉与工具能力；当前接口与服务商范围见[模型配置](model-and-channel-setup.md)和[兼容矩阵](compatibility.md)。

## Copilot 实时语音

[Copilot 契约](copilot-voice.md)定义持续监听、1.5 秒提交、转写修订、同会话连续补充和可打断播报。持久输入基础已存在；真实收音、语音服务及播放打断尚未交付。

1. 在 Agent 下接入流式 STT/TTS，分别管理麦克风、设备声音与模型播报。
2. 接通持续采集、端点判断和有序转写，复用现有会话接受链。
3. 提供回声处理、低延迟反馈及播放 generation，新讲话立即停止过时播报。
4. 单独提供客体麦克风路由，用于语音消息与指定测试端点的应用通话。

## 通话与扩展

通话需要独立会话、线路服务与经过核对的拨号、接听、静音、挂断生命周期。SIP、用户配置的电话服务和物理设备属于独立扩展。模拟器、root、设备名称或 eSIM 界面本身不提供运营商线路与号码；真实通信需明确接收人、费用与录音范围。

[可选角色应用](companion-extension.md)、更多设备和系统模板可独立扩展核心工作区。扩展与程序更新须保持已有用户状态兼容。

## 更新与分发

采用签名版本化制品、兼容/容量检查、一致备份、明确迁移、健康检查及激活/回退。对用户目录直接 Git pull 不是更新器。详见[程序与数据边界](distribution.zh-CN.md)和[备份恢复](backup-restore.zh-CN.md)。

原创代码继续使用 Apache-2.0；第三方软件、系统与素材保留各自许可和对应源码要求。分发审查、实机安装、编译与协议支持分别记录。
