# 开发路线

下载和平台要求见[发行状态](release-status.md)。

## 完整本地安装

- 随包提供干净的 Android/Linux 系统基础、匹配模拟器、预构建服务与运行环境。
- 在一个客户端中完成手机、电脑与模型配置，支持资源准备续跑及真实设备就绪检查。
- 允许调整设备资源预设，保留已有设备盘、账号与聊天。默认工作区包含一台手机和一台电脑。
- 用 QEMU 和 Windows Hypervisor Platform 构建离线 Linux 宿主，在全新 Windows 11 x64 上验收启动、Android 配对、桌面控制和重启。
- 在 macOS 和 Windows 实机上验证安装恢复、宿主重启和版本更新。

安装约定见[发行标准](distribution-requirements.md)、[运行组件](runtime-bundles.md)及[一体化宿主](integrated-hosts.md)。

## 响应速度与持续工作

降低冷启动、设备控制及输入到响应的延迟，分别计量冷/热状态下的画面采集、传输、模型调度与播放。用户补充应及时调整当前任务，不必等待长时间的前台操作或重新建立对话。

设备动作在取消与恢复后保留原有身份，未知结果先观察再决定后续操作。长时后台任务保留检查点，通知与用户指令共用同一持久会话路径。

## 模型与连接应用

模型/API、连接应用与记忆按配置保存。两台设备使用同一个当前 Agent。Skill、知识库和工作文件共享。

继续扩展模型发现与手动 ID 回退、绑定配置版本的能力检测、服务商协议回归、OAuth 和本地模型。当前接口与服务商见[模型配置](model-and-channel-setup.md)和[兼容矩阵](compatibility.md)。

## Copilot 实时语音

[Copilot 契约](copilot-voice.md)定义持续监听、1.5 秒提交、转写修订、同会话连续补充和可打断播报。浏览器 PCM 收音、Agent 语音适配、持久文字与纠错提交、流式可打断 WAV 播放已通过隔离传输测试。真实麦克风与语音服务待验证。

1. 使用真实麦克风与配置的服务商验收多语言、纠错、噪声、回声和设备切换。
2. 分别测量收音至最终文字、首句播报、播放打断与首个真实设备动作的延迟。
3. 扩展服务商协议及原生语音对语音，保持麦克风、设备声音和播报各自的生命周期。
4. 单独提供客体麦克风路由，用于语音消息与指定测试端点的应用通话。

## 通话与扩展

通话需要独立会话、线路服务和拨号、接听、静音、挂断控制。扩展可接入 SIP、用户配置的电话服务或物理设备。呼叫前显示接收人、费用和录音范围。

[可选角色应用](companion-extension.md)、更多设备和系统模板可独立扩展核心工作区。扩展与程序更新须保持已有用户状态兼容。

## 更新与分发

采用签名版本化制品、兼容与容量检查、一致备份、迁移、健康检查、激活与回退。详见[程序与数据边界](distribution.zh-CN.md)和[备份恢复](backup-restore.zh-CN.md)。

原创代码继续使用 Apache-2.0；第三方软件、系统与素材保留各自许可和对应源码要求。
