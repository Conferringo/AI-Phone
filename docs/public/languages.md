# Interface languages / 界面语言

Ten interface catalogs are available: English, 简体中文, 繁體中文, 日本語, 한국어, Deutsch, Français, Español, Русский and العربية. Russian and Arabic cover the same 382 control keys as the other catalogs. Arabic uses right-to-left text; device coordinates and the perspective stage remain left-to-right.

Choose a language in the native client's first setup, or in `./ai-phone configure`. In the workbench, the language glyph immediately left of Skills opens the language list on hover, click or Arrow Down. Escape closes it. The configuration center does not duplicate this entry. Selection applies immediately and persists in the browser cookie.

Priority: explicit native-client choice → browser cookie → private installation default → browser preference. Guest OS language, input methods, Agent memories and existing conversations are not changed. Raw tool results, third-party notifications and some backend diagnostics retain their original language; complete multilingual accessibility/native acceptance remains pending.

## 简体中文

界面共十种语言，安装配置和客户端初次配置可选择。日常入口位于 Skill 左侧，显示当前语言简称；支持悬浮、点击、键盘展开，Esc 收起，刷新保留。俄语和阿拉伯语均已补齐382项控件翻译；阿拉伯语采用RTL文字排版，设备操作坐标不反转。

优先级为本次客户端明确选择、浏览器cookie、安装默认、浏览器偏好。当前仅切换应用界面，不自动重启或更改客体系统语言，不修改聊天和记忆。工具原文及部分诊断保留原始语言；翻译键齐全不代表各平台人工验收完成。
