# Interface languages / 界面语言

Ten interface catalogs are available: English, 简体中文, 繁體中文, 日本語, 한국어, Deutsch, Français, Español, Русский and العربية. Russian and Arabic cover the same 382 control keys as the other catalogs. Arabic uses right-to-left text; device coordinates and the perspective stage remain left-to-right.

Choose a language in the native client's first setup, or in `./ai-phone configure`. In the workbench, the language glyph immediately left of Skills opens the language list on hover, click or Arrow Down. Escape closes it. Selection applies immediately and persists in the browser cookie.

Resolution order is native-client choice → browser cookie → installation default → browser preference. The selection applies to the interface. Tools, notifications and some diagnostics retain their original language.

## 简体中文

界面共十种语言，安装配置和客户端初次配置可选择。日常入口位于 Skill 左侧，显示当前语言简称；支持悬浮、点击、键盘展开，Esc 收起，刷新保留。俄语和阿拉伯语与其他语言一样，覆盖382项控件翻译；阿拉伯语采用RTL文字排版，设备操作坐标不反转。

优先级为客户端明确选择、浏览器cookie、安装默认、浏览器偏好。选择只作用于应用界面。工具输出、外部通知和部分诊断保留原语言。
