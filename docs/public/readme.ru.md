# AI Phone

[English](../../README.md) · [Все языки](../../README.md) · Apache-2.0

## Загрузка и статус

Полные установочные пакеты пока недоступны. Настройка проходит по шагам: ресурсы устройств → модель → рабочее пространство. Полный пакет содержит базовые системы Android/Linux, эмулятор и готовые сервисы. Клиент настраивает окружение; пользователю не нужно искать образы или компилировать сервер.

Цели сборки: macOS Apple Silicon, Windows x64, Linux x64/ARM64 и Android ARM64. Хост Android требует root и KVM. Наличие пакетов и фактически проверенные платформы указаны в статусе выпуска.

## Возможности и сценарии

AI Phone объединяет настоящий гостевой Android, лёгкий рабочий стол Linux и Агентов. По умолчанию доступны один телефон и один компьютер. У каждого устройства своя переписка; можно назначить одного общего Агента или разные модели.

- Работа с приложениями, например WeChat: наблюдение интерфейса, уведомления и ответы по поручению пользователя. Ограничения аккаунта и приложений продолжают действовать.
- Рабочий процесс: получить файл на телефоне, передать на Linux, обработать и проверить таблицу, вернуть результат. Передача файла между устройствами и отправка адресату проверяются отдельно.
- Длительные задачи: новые инструкции прерывают генерацию, сохраняя сообщения и историю действий. Уведомления могут пробуждать Агента. Автономное исследование имеет отдельную паузу для каждого устройства.
- Общие навыки, связанные документы базы знаний и рабочие файлы; память, модели/API и внешние подключения принадлежат Агентам. Приложения Clash находятся внутри гостевых систем; хост по умолчанию работает напрямую.

Действия привязаны к наблюдениям, устройству, задаче, эпохе управления и уникальному ID. Неизвестный результат сначала проверяется наблюдением. Модель всё ещё может ошибаться; журналы не являются гарантией точности.

## Архитектура и данные

`apps/web`: Next.js App Router, React, Tailwind, shadcn. `apps/client`: Tauri 2. `crates`: Rust, Axum, Tokio. `packages/protocol`: protobuf. PostgreSQL/SQLx хранит состояние; Redis зарезервирован для необязательного кеша, а не очереди задач. Bun и Cargo — инструменты разработки; Compose запускает сервисы. `infra`, `scripts`, `skills`, `config` содержат среду выполнения и встроенные возможности.

Код отделён от пользовательского состояния. Диски, аккаунты, переписка, вложения и ключи не публикуются. Обновления должны использовать версионированные пакеты, резервное копирование, миграции и откат. Прямой `git pull` поверх пользовательских данных не является механизмом обновления.

## Развитие, ограничения и лицензия

Приоритеты: полноценные пакеты, восстановление установки, подписанные обновления, устойчивый агентный цикл, звук/ввод, проверка моделей и специализированные навыки приложений. Далее — голос и экспериментальная телефония; реальные звонки/eSIM пока не реализованы. Настольный питомец удалён из ядра и рассматривается только как расширение.

Интерфейс и первичная настройка поддерживают десять языков. Переключатель слева от Skills меняет интерфейс; язык гостевых ОС и исходные тексты инструментов автоматически не переводятся.
