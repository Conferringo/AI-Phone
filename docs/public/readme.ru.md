# AImanity

[English](../../README.md) · [Все языки](../../README.md) · Apache-2.0

## Загрузка и статус

Публичная загрузка готовится. [Релизы GitHub](https://github.com/MrMilkDragon/AImanity/releases)

Требуется macOS 14.4 или новее на Apple Silicon либо Windows 11 x64. В каждый установщик входят Android, Linux, эмулятор и локальные службы.

## Возможности и сценарии

AImanity объединяет телефон Android и рабочий стол Linux в одной беседе с одним активным агентом. Профили моделей можно сохранять и выбирать в настройках.

- Работа с приложениями, например WeChat: наблюдение интерфейса, уведомления и ответы по поручению пользователя. Ограничения аккаунта и приложений продолжают действовать.
- Рабочий процесс: получить файл на телефоне, передать на Linux, обработать и проверить таблицу, вернуть результат. Передача файла между устройствами и отправка адресату проверяются отдельно.
- Длительные задачи: новые инструкции прерывают генерацию, сохраняя сообщения и историю действий. Уведомления могут пробуждать Агента. Liberty работает с обоими устройствами.
- Общие навыки, связанные документы базы знаний и рабочие файлы; память, модели/API и внешние подключения принадлежат Агентам. Приложения Clash находятся внутри гостевых систем; хост по умолчанию работает напрямую.

Действия привязаны к наблюдениям, устройству, задаче, эпохе управления и уникальному ID. Неизвестный результат сначала проверяется наблюдением.

## Архитектура и данные

`apps/web`: Next.js App Router, React, Tailwind, shadcn. `apps/client`: Tauri 2. `crates`: Rust, Axum, Tokio. `packages/protocol`: protobuf. PostgreSQL/SQLx хранит состояние; Redis зарезервирован для необязательного кеша, а не очереди задач. Bun и Cargo — инструменты разработки; Compose запускает сервисы. `infra`, `scripts`, `skills`, `config` содержат среду выполнения и встроенные возможности.

Код отделён от пользовательского состояния. Диски, аккаунты, переписка, вложения и ключи не публикуются. Обновления должны использовать версионированные пакеты, резервное копирование, миграции и откат. Прямой `git pull` поверх пользовательских данных не является механизмом обновления.

## Развитие, ограничения и лицензия

Приоритеты: полноценные пакеты, восстановление установки, подписанные обновления, устойчивый агентный цикл, звук/ввод, проверка моделей и специализированные навыки приложений. Далее — голос и экспериментальная телефония.

Интерфейс и первичная настройка поддерживают десять языков. Переключатель слева от Skills меняет интерфейс; язык гостевых ОС и исходные тексты инструментов автоматически не переводятся.
