# AI Phone

[English](../../README.md) · [جميع اللغات](../../README.md) · Apache-2.0

## التنزيل والحالة

حزم التثبيت الكاملة غير متاحة للتنزيل بعد. تسلسل الإعداد هو موارد الأجهزة ← النموذج ← مساحة العمل. تحتوي الحزمة الكاملة على أنظمة Android/Linux الأساسية والمحاكي والخدمات المبنية مسبقًا. يجهز العميل البيئة، فلا يحتاج المستخدم إلى البحث عن صور الأنظمة أو تجميع الخادم.

أهداف البناء هي macOS Apple Silicon وWindows x64 وLinux x64/ARM64 وAndroid ARM64. يتطلب مضيف Android صلاحيات root وKVM. يوضح سجل الإصدار توفر الحزم والمنصات التي اختُبرت فعليًا.

## الوظائف والسيناريوهات

يجمع AI Phone بين Android ضيف حقيقي وسطح مكتب Linux خفيف ووكلاء ذكاء اصطناعي. الإعداد الافتراضي هاتف واحد وحاسوب واحد. لكل جهاز محادثته المستمرة، مع وكيل مشترك أو نماذج مستقلة.

- تشغيل التطبيقات مثل WeChat: مراقبة الشاشة والإشعارات والرد وفق تعليمات المستخدم. تبقى قيود الحساب والتطبيق نافذة.
- العمل بين الأجهزة: استلام ملف في الهاتف ونقله إلى Linux ومعالجة جدول والتحقق منه وإرجاعه. اكتمال النقل وتسليم الملف إلى جهة اتصال نتيجتان منفصلتان.
- المهام المستمرة: إضافة تعليمات ومقاطعة التوليد مع حفظ الرسائل وسجل الإجراءات. يمكن للإشعارات تنشيط الوكيل، ويتيح الاستكشاف الذاتي إيقافًا مستقلًا لكل جهاز.
- المهارات ومستندات المعرفة المرتبطة وملفات العمل مشتركة. النماذج وAPI والذاكرة والاتصالات الخارجية خاصة بالوكيل. يعمل Clash كتطبيق داخل كل نظام ضيف؛ اتصال المضيف مباشر افتراضيًا.

ترتبط الإجراءات بملاحظات الشاشة والجهاز والمهمة ودورة التحكم ومعرّف فريد. تُفحص النتائج المجهولة قبل إعادة التنفيذ. قد يسيء النموذج فهم الواجهة؛ السجلات لا تضمن دقة كاملة.

## التقنية والبيانات

`apps/web`: ‏Next.js App Router وReact وTailwind وshadcn. ‏`apps/client`: ‏Tauri 2. ‏`crates`: ‏Rust وAxum وTokio. ‏`packages/protocol`: ‏protobuf. يخزّن PostgreSQL/SQLx الحالة، وRedis مخصص للتخزين المؤقت الاختياري وليس طابور المهام. أدوات التطوير Bun وCargo، والخدمات عبر Compose. تحتوي `infra` و`scripts` و`skills` و`config` بيئات التشغيل والقدرات المدمجة.

المصدر منفصل عن بيانات المستخدم. لا تُنشر أقراص الأجهزة أو الحسابات أو المحادثات أو المرفقات أو المفاتيح. تحتاج التحديثات حزمًا ذات إصدارات ونسخًا احتياطية وترحيلًا وتراجعًا؛ ليس `git pull` فوق بيانات المستخدم آلية تحديث مناسبة.

## الاتجاهات والقيود والترخيص

الأولويات: الحزم الكاملة، استئناف التثبيت، تحديثات موقعة، استقرار الوكيل، الصوت والإدخال، التحقق من النماذج ومهارات التطبيقات. لاحقًا: الصوت والاتصالات التجريبية؛ المكالمات الفعلية وeSIM غير منفذة.

تدعم الواجهة والإعداد الأولي عشر لغات. مفتاح اللغة يسار المهارات يبدّل الواجهة مع اتجاه RTL للعربية؛ لا يغيّر لغة أنظمة الأجهزة أو يترجم مخرجات الأدوات تلقائيًا.

المستخدم مسؤول عن الأذونات والحسابات والأفعال الخارجية وشروط التطبيقات. لا تستخدم النظام للاحتيال أو انتحال الهوية أو التصرف دون موافقة. المصدر الأصلي مرخّص Apache-2.0، وتحتفظ التبعيات بتراخيصها. النص لا يعفي من المسؤولية القانونية.
