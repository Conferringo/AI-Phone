# Offline Android corresponding source

Aluminum includes an Android guest, a native virtual machine engine and ADB. The installer’s `android.payload` contains the locked AOSP and kernel manifests, exact kernel configuration, partition notices, SPDX inventory and component licenses. The `platform-tools` directory contains ADB’s `REBUILD.md`, `Source-Dependencies.txt` and libusb license.

## Native engines

- **macOS.** Avo 1.1.0 build 126 uses the BSD-3-Clause `avo-vmm` engine. Build from the pinned `engine/hvf` workspace with `cargo build --locked --release -p avo-vmm` and sign the executable with the workspace’s Hypervisor entitlement. [Immutable release](https://github.com/nizwar/avo/releases/tag/v1.1.0) · [Pinned engine workspace](https://github.com/nizwar/avo/tree/23fbb0d22dec815c84d704d91c76b6a4406d7bbc/engine/hvf) · [Entitlements](https://github.com/nizwar/avo/blob/23fbb0d22dec815c84d704d91c76b6a4406d7bbc/engine/hvf/hypervisor.entitlements)
- **Windows.** QEMU 11.1.3 uses the Windows Hypervisor Platform. The runtime inventory records the exact DLL versions, source locations and firmware. [QEMU source archive](https://download.qemu.org/qemu-11.1.3.tar.xz) · [SeaBIOS source](https://gitlab.com/qemu-project/seabios/-/tree/b52ca86e094d19b58e2304417787e96b940e39c6) · [AImanity factory](../../../scripts/tooling/windows-qemu.ts)

## ADB 36.0.1

Both host builds use android-tools-static commit `cdadf2ecf68bd3b8c8971b9214cd2bc4e2d77127` and libusb 1.0.29. Download the patched source archive for the target, then follow the bundled `REBUILD.md`. Its dependency list records the source and Meson wrap patch URLs. [Release](https://github.com/meator/android-tools-static/releases/tag/36.0.1) · [AOSP ADB commit](https://android.googlesource.com/platform/packages/modules/adb/+/78f769e0904c21771cccf6e4e7b239b21800e189) · [libusb source](https://github.com/libusb/libusb/releases/download/v1.0.29/libusb-1.0.29.tar.bz2) · [Meson wrap patch](https://wrapdb.mesonbuild.com/v2/libusb_1.0.29-2/get_patch)

- **macOS.** Use the `macos arm64.ini` native file and `-Dlibusb:default_library=shared`. Build `vendor/adb`, set the libusb install name to `@loader_path/libusb-1.0.0.dylib` and sign both files. Replace the dylib with an ABI-compatible build to use a modified libusb. [Patched source archive](https://github.com/meator/android-tools-static/releases/download/36.0.1/android-tools-static-36.0.1-src.tar.gz)
- **Windows and Linux x64.** Use `release_configuration.ini`, `release_configuration_fullstatic.ini` and `release_configuration_standardlayout.ini` in the matching platform’s Meson setup. Edit the extracted `libusb-1.0.29` source and rebuild to relink. Windows uses MSYS2 UCRT64 and installs `adb.exe` alongside `AdbWinApi.dll` and `AdbWinUsbApi.dll`. Linux builds the `vendor/adb` target. [Patched Windows source archive](https://github.com/meator/android-tools-static/releases/download/36.0.1/android-tools-static-36.0.1-src-windows.zip) · [Patched Linux source archive](https://github.com/meator/android-tools-static/releases/download/36.0.1/android-tools-static-36.0.1-src.tar.gz)
