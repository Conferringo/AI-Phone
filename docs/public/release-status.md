# Release status / 发行状态

[AI Phone 0.1.0](https://github.com/Conferringo/AI-Phone/releases/tag/v0.1.0)

| System | Installer | Host requirements |
| --- | --- | --- |
| macOS | DMG | Apple Silicon, macOS 14.4 or later |
| Windows | EXE | Windows 11 x64 with hardware virtualization |

Both packages include Android, Linux and local services. Windows uses system WebView2 and QEMU with Windows Hypervisor Platform.

The macOS disk image and Windows archive passed file readback. Both packages are unsigned. Clean-host installation remains unverified. [Report an issue](https://github.com/Conferringo/AI-Phone/issues/new/choose)

## 中文

macOS 支持 Apple Silicon 和 macOS 14.4 以上版本。Windows 支持开启硬件虚拟化的 Windows 11 x64。两端安装包内置 Android、Linux 和本地服务。

两端安装包已通过包内文件核对，均未签名。全新主机安装待实测。
