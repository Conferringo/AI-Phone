# 技术实现

[English](architecture.en.md)

| 组件 | 实现 | 职责 |
| --- | --- | --- |
| 工作台 | Next.js App Router/Turbopack、React、Tailwind、shadcn/ui、GSAP | 真实画面、设备透视切换、每设备对话、配置与共享资源 |
| 助手 | Rust/Axum/Tokio | 持久任务循环、模型适配、调度、记忆、知识、权限与完成审计 |
| 手机执行器 | Rust + ADB + Android桥接 | 当前观察、控件/OCR定位、输入/手势、epoch、动作去重 |
| 电脑客体 | Rust + X11 + FFmpeg | 画面与输入、光标回执、音频监督、连接采集租约和持久通知 |
| 媒体 | Bun、Android gRPC、FFmpeg/X11 | JPEG帧流、PCM音频；原生触点/指针进入同一画面 |
| Linux电脑 | Docker、Debian/Openbox、Xvfb、桌面桥 | computer use、办公软件、客体sudo与文件处理 |
| 渠道 | Bun、官方SDK/Bot API及本地WhatsApp适配 | Agent级凭据、私聊配对、入站排队、送达状态 |
| 存储 | PostgreSQL/SQLx；私有数据文件 | 注册表、连续对话、模型版本与审计；Redis预留，尚未分发任务 |

浏览器业务请求使用 `application/x-protobuf`，契约在 `packages/protocol/proto`；媒体字节和健康检查例外。流式业务事件使用protobuf WebSocket帧，不要与模型SSE混淆。

Android无桌面入口的辅助服务提供按需、只读的原生控件层级请求，由系统`DUMP`权限保护。Rust优先接收绑定当前请求ID的完整回执，再使用UIAutomator及OCR后备；层级正文不包含密码文字。观察与动作校验分别负责数据读取和控制权，快速快照不替代动作后的结果核对。

## 一次真实操作

用户或已配对渠道 → 持久run → 固定Agent与模型版本 → Skill/当前观察 → 模型提出动作 → owner/设备/run/epoch/action_id校验 → 客体执行 → 动作后观察 → 工具结果落盘 → 下一轮 → 独立完成核验。

动作注入成功不代表目标完成；结果未知先观察，不自动重放。读取Skill不等于操作，通知预览不等于完整消息，输入草稿不等于已发送。界面保留公开进展、实际工具输入输出和审计，不伪造模型私有思维链。

不同设备的任务独立推进。PostgreSQL在领取任务时授予设备独占租约，主设备和借用设备均保留到本次结果提交完成；模型和客体I/O不占用SQL事务。取消针对指定run，前台切换不停止其他任务。跨设备控制遇到占用时等待，不抢走其他任务的设备；设备消息提供持久交接。启动恢复只释放上个进程的租约，保留检查点、结果未知的动作及等待期限。

设备被占用时，输入派发前返回`device_busy`，明确本次未执行并建议等待或交接，不触发画面重试。其他错误保留原有执行状态合同，结果未知时仍须先观察。

等待资源和成功的等待请求既不消耗执行失败额度，也不算执行进展。真正失败的操作仍遵守原阈值，包括参数无效的等待和计划请求。

Responses、Chat Completions与原生Anthropic Messages复用同一执行引擎；后者转换函数调用、结果与图片，不改变持久证据。拒绝截断、过滤、缺少终止标志或无效工具参数的输出。新模型须实际通过能力探测，不能只检查HTTP连通。

Responses完成事件中的响应状态若明确不是completed，输出会在转为工具提案前被拒绝。有效完整输出原样保留，继续交由既有证据和服务商回放流程处理。

## Skill 存储

PostgreSQL 保存已提交的 Skill 正文。每个安装实例使用每 Skill 的操作系统文件锁串行发布本地投影，原子替换 `SKILL.md` 并同步磁盘。即使异步调用被取消，实际写入任务仍持有锁直至文件操作结束。文件读写不占用数据库事务；读取及启动时根据持久正文修复投影，并保留辅助资源。

## 设备与文件

默认一手机一电脑；root/sudo分别限定Android/Linux客体，不授予宿主任意执行权。数据线是持久连接关系，传输需连接及设备授权正确，核对方向、路径与哈希；断开后拒绝新传输。每台设备保留独立对话/草稿，即使共用Agent。

已验证测试文件的手机→电脑→手机处理链路；不等于微信实号交付。执行账本持久保留和隔离worker/数据库故障恢复已通过；宿主休眠/重启、长时间多设备运行及通知/任务竞争仍需发行验收。见[恢复验证](task-recovery.md)及[发行状态](release-status.md)。

程序使用版本目录；user保存私有状态，源码包不带用户数据。开发工作区仍保留原data目录，新managed staging使用受控链接接到独立user目录。见[发行与升级](distribution.zh-CN.md)。
