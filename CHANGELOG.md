# Changelog

## 2026-10-30 · Initial source snapshot

- Continuous conversation geometry transitions across portrait/landscape layouts, without text scaling or opacity flashes.
- One exploration pause/resume control per conversation; phone and computer capabilities enabled by default, with durable pauses and failure reporting.
- Freehand map routes, bounded waypoint simplification and cancellation cleanup.
- Knowledge graph, text editing/saving and document links; removed import, trash view, view switching and duplicate preview.
- Ten interface/setup languages, including Russian and Arabic/RTL; a single workbench language entry beside Skills and translated project overviews.

This is a development source snapshot. Complete Android/Linux image, emulator and prebuilt-service distributions remain unavailable. No product installer is released by this snapshot. See [release status](docs/public/release-status.md).
